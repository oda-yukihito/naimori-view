プライバシーポリシー

最終更新: 2026-09-30

1. 収集しないデータ

当ツールは、ユーザーのTikTok・YouTube・Instagramアカウント情報、閲覧履歴、個人を特定できる情報を一切収集しません。

2. 処理の場所

APIキー・アクセストークン・動画データの処理はすべてユーザーのローカル環境で行われます。外部サーバーに送信されることはありません。

3. Cookie・トラッカー

当ツールはCookieやトラッカーを使用しません。

4. 問い合わせ

プライバシーに関するお問い合わせは、YouTube Data API keyの環境変数設定以外はサポート対象外です。
